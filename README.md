# INR – Infinite Next Reality 🚀

INR (Infinite Next Reality) is a full-stack SaaS starter platform designed to help developers build scalable, production-ready web applications.

## 🧠 Tech Stack
- Frontend: React (Vite) + Tailwind CSS + Framer Motion
- Backend: Node.js + Express
- Database: MongoDB (Mongoose)
- Authentication: JWT
- API Communication: Axios

## ✨ Features
- Modern UI with responsive design
- Modular backend architecture
- REST API integration
- Contact/lead management system
- Scalable folder structure for SaaS apps

## 🚀 Getting Started
1. Clone the repo
2. Install dependencies (client & server)
3. Run frontend and backend servers
4. Configure environment variables

## 🎯 Goal
To provide a clean, extensible foundation for building SaaS products like dashboards, AI tools, analytics platforms, and more.
